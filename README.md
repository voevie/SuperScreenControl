# SuperScreenControl（超级屏控）
## Introduction(介绍)
- 支持多Android、iOS设备连接，自动连接、多台设备同时连接（群控、矩阵）；
- 支持Android的USB连接和WiFi局域网连接，支持iOS设备的USB连接；
- 支持电脑端控制Android、iPhone手机，包括应用启动、安装应用、模拟设备操作（点击、双击、滑动、返回、亮屏、息屏、关机、调音量）等基本操作；
- 支持自动化脚本创作，根据Android、iPhone手机的基本操作事件，直接拖动生成流水线图，生成自动化运行脚本；
- 支持自动化脚本的运行、多设备批量运行、分组脚本运行、独立脚本运行；
- 支持多种方式的逻辑判断、设备判断；
- 支持键盘快捷键模拟手机事件，可以通过键盘映射成手机的操作；
- 支持AI大模型手机界面分析、文本生成、上下文分析以及问答；
- 支持实时截屏、文件拖拽的功能；
